# Projects portfolio

Portfolio page for three fitness apps I worked on as business analyst. I gathered the requirements, wrote the specs and acceptance criteria, and signed off each release. The code was written by Claude Code.

- **Physique Blueprint**: live app at https://kanadhibhotla-sri-charan.github.io/workout-blueprint/
- **Workout Programmer**: read-only demo in `demos/workout/`
- **Food Tracker**: read-only demo in `demos/food/`

The demos are static copies of the real app interfaces. They replay responses recorded from the apps running on synthetic sample data, so nothing in them is real personal data and nothing can be saved.

Site: https://kanadhibhotla-sri-charan.github.io/projects-portfolio-versions/
